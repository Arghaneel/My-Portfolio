A Java Swing desktop application that digitises an electricity utility's workflow: customer registration, meter-reading entry, slab-based bill calculation, payment collection and invoice generation, with role-based access control.

Data lives in MySQL via JDBC, organised with object-oriented models and DAOs.

KEY
Scene 02 — What it does

Key features /

Feature 01

Role-based logins: Admin, Employee and Viewer portals, plus a separate Customer portal.

Feature 02

Slab-based billing engine with separate rules for Domestic and Commercial customers.

Feature 03

Admin control room with KPI stats, configurable slab and tax rates, JSON backup/restore and CSV export.

Feature 04

Usage analytics with custom line, bar and donut charts for bill trends and consumption.

Feature 05

Invoice generation with print-to-PDF and HTML export.

Feature 06

Demo mode that runs without MySQL using in-memory data.

Four portals, one billing engine

A Java Swing desktop app that runs an electricity utility's workflow: customer registration, meter readings, slab-based billing for domestic and commercial customers, payments and invoices. Role-based portals, MySQL over JDBC with object-oriented models and DAOs, usage charts, JSON backup and CSV export, plus a demo mode that runs without a database.
